# Apirra Backend

Backend service for [Apirra](https://apirra.malindasampath.com), the browser-based OpenAPI explorer. The frontend lives at [apirra-saas-frontend](https://github.com/malinda-sampath/apirra-saas-frontend).

> Work in progress: the service code hasn't been added yet.
